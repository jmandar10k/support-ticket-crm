# Support Ticket CRM

A full-stack customer support CRM system built using FastAPI, SQLite, HTML, CSS and JavaScript.

## Features

- Create Tickets
- Search Tickets
- Filter by Status
- Ticket Detail View
- Update Status
- Add Notes
- Dashboard View

## Tech Stack

Backend:
- FastAPI
- SQLAlchemy
- SQLite

Frontend:
- HTML
- CSS
- JavaScript

## Run Locally

Install:

pip install -r requirements.txt

Run:

uvicorn backend.main:app --reload
